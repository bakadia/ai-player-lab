## 1. 名字

`ai-player-lab`：自动玩家实验室。

- 不叫 `backpack-hero-*`：这里会有第二个、第三个游戏。
- 不叫 `aipeiwo-*`：陪玩是剑三那边的产品名；这里是工程实验室。
- `lab` 是故意的：允许失败、允许换实现、允许把某个 adapter 扔掉重写。

## 2. 三层

| 层 | 放什么 | 不放什么 |
|---|---|---|
| `core/` | 契约、runner、watchdog、校验、评测、账本 | 任何游戏名、任何截图/内存代码 |
| `games/<game>/adapter/` | 把游戏状态翻译成 `Observation`；把 `Action` 翻译成游戏操作 | 策略、评分、重试逻辑 |
| `games/<game>/agent/` | 这个游戏的策略、装配、单局入口 | 通用能力（上移 `core/`） |
| `games/<game>/bridge/` | 游戏内执行器（mod / 注入 / 像素） | 决策 |

依赖方向：`games → core`，**core 不反向依赖任何游戏**。

## 4. 迁移（一次性）

在**普通 PowerShell**里跑，不要在 DSH 会话里跑（当前 cwd 就是源目录）：

```powershell
# 1. 确认目标不存在
Test-Path 'D:\projects\ai-player-lab\games\backpack-hero'   # 应为 False

# 2. 移动并改名
Move-Item -LiteralPath 'D:\projects\backpack-hero-aipeiwo' `
          -Destination 'D:\projects\ai-player-lab\games\backpack-hero'

# 3. 检查
Get-ChildItem 'D:\projects\ai-player-lab\games\backpack-hero'
```

如果 `Move-Item` 报「目录正在使用」：关掉 DSH 会话/资源管理器窗口再试，或先用
`robocopy 'D:\projects\backpack-hero-aipeiwo' 'D:\projects\ai-player-lab\games\backpack-hero' /E /MOVE`。

迁移后在 DSH 里把工作区切到 `D:\projects\ai-player-lab`（或 `...\games\backpack-hero`）。

## 5. 约定

1. **契约优先**：先改 `contract.py`，再改 adapter；不允许 adapter 私造字段。
2. **动作必须可验证**：每个 `Action` 带 `Expect`；没有 `Expect` 的动作视为 bug。
3. **core 不 import 游戏**：`grep -r "backpack\|jx3" core/` 必须为空。
4. **adapter 不做策略**：adapter 只翻译，不评分、不重试；策略放 `games/<game>/agent/`。
5. **日志即资产**：每局 JSONL；能回放才算跑过。
6. **急停**：`runtime/halt` 存在即停；这是从剑三带过来的硬规矩。
7. **时间弹性**：计划是节奏参考，不是承诺；每周至少留下一个「可复现的结论」。
