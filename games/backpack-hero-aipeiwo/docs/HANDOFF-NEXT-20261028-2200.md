### 3.2 为什么 v8.6 的 `via=bag` 还不够

`ItemMovement.EndDrag()` 的 IL：

```
transform.position = startPosition;
transform.rotation = startRotation;
AddToGrid(false);          // -> GetGridObject() + GridObject.SnapToGrid()
...
isDragging = false;
```

`place_item` 现在是 `StartDrag → transform.position = target → EndDrag`，
所以 EndDrag 会把物品**拉回 startPosition**（掉落区）再 AddToGrid，
目标格完全被忽略。parent 设对了也没用。

### 3.3 三个候选修法（按推荐顺序）

1. **改 startPosition**（最小）：
   ```
   im.StartDrag();
   transform.position = target;
   World.SetField(im, "startPosition", target);
   World.SetField(im, "startRotation", Quaternion.identity);
   EndDrag();
   ```
   EndDrag 会自己把 transform 设到 target 再 AddToGrid/SnapToGrid。
2. **`MoveItemTowardsGrid(im)`**：先把 transform 设到 target，再调
   `GameManager.MoveItemTowardsGrid(im)`（private，反射）。它用 item 位置向
   `itemsParent` 射线找 GridSquare/Item，不依赖鼠标。
3. **直接 `GridObject.SnapToGrid()`**：设置 `parentInventoryGrid`/`parentTransform`
   到背包 parent，把 transform 放 target，再调 `SnapToGrid()`；可能需要补
   `GridSquare.AddToGrid`。
