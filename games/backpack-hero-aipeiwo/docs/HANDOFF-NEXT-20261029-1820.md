- **E17**：别拿被测试钩子污染过的状态下结论（扩容"恒为 0"就是这么错的）。
- **E18**：`start_event` 对「点物体」事件（SCI type 11 / Chance type 4）永远是空操作，
  `relevant_event=null`；SCI 走 `play_event`，Chance 目前只能拉黑。
- **E19**：**预期内的无变化不算卡死**——扩容点击要等 `finish_level_up` 才 +格，
  摆放失败是"换格/记 explored 还能继续"，两者 `changed=False`，直接判死会毁掉整局。
- 采样器跨局会继续写同一个文件 → 单局统计必须 `--stop-on-dead`。
- 部署：`bridge/build.ps1` → `Stop-Process -Name "Backpack Hero"` → `bph.cmd deploy`
  → `launch_app`（本会话起 shell 能直接杀进程，不用再提权）。
- 控制台 GBK：脚本别 print `✓`；`python - <<'PY'` 在 pwsh 里不支持，落成文件；
  PowerShell 传 JSON 参数要 `\"` 转义。
