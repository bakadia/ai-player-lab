## 2. 已确认（别重查）

- `probe_fit` 的 `cell` 是**锚点**＝物品 transform 落到的那个格子（3 格长条的锚点是中间那格）。
- `needs` = `ItemMovement.GetSpacesNeeded()` = 各 BoxCollider2D `size.x*size.y` 之和，
  **不随旋转变**；真正能不能放看 footprint。
- 占用唯一事实是 `gridPositions`（`Actions.OccupiedCells`），**不要用 `containsItem`**
  （会滞后；move/rotate 的校验这班已经改成按 gridPositions 算）。
- `AddToGrid(bool)` 是 **public**，内部就是 EndDrag 的最后一步（SnapToGrid + 占格判定 +
  设 parent + `objsInGrid+1`）。对「已经不在格子里」的物品，直接调它 = EndDrag。
- `drop_item` 之后物品是 loose，离开房间会被游戏清掉；`items_loose` 在 delta 里是**差值**。
- `state.backpack.free_squares` 偶尔写 `-1`（本次 bag 刚满时看到一次）——`CountFreeSquares`
  的 catch 分支。看到 -1 别当「满」，用 probe 的 `free_squares` 或数 cells。
- 地图的 `legal` 里 `move_to_room` **会列出走不到的房间**；走过去 30 秒超时。
  这次在 `r-5844 → r-5858` 上踩到（`loop.py` 的 `bad_rooms` 就是为此）。房间要**一格一格**走。
